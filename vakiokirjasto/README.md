# RLML-vakiokirjasto (STD)

[RLML](../README.md) › RLML-vakiokirjasto (STD)

Oct 24, 2026 · @Seppo Säämäki

Vakiokirjasto (STD) on RLML:llä ja RogueScriptillä kirjoitettu kirjasto, joka tekee tavallisesta roguelikesta pelattavan ilman pelin omaa logiikkaa. Se tarjoaa liikkeen, törmäyksen, lyönnin, kuoleman, kartanvaihdon, vihamielisyyden, kuulemisen ja niiden viestit. Viittaukset “[moottoridokumentti](../moottori/README.md)”, “[RogueScript](../roguescript/README.md)” ja “[dataformaatit](../dataformaatit/README.md)” tarkoittavat RLML 0.3:n muita dokumentteja.

**Tila 24.10.2026:** ensimmäinen luonnos valmiustestin päätösten pohjalta. Dokumentti kokoaa muissa dokumenteissa esimerkkeinä olleet STD-nimet yhdeksi sopimukseksi ja lisää puuttuvat. Avoimet kohdat ovat luvussa [14](14-avoimet-kysymykset.md).

Muutoshistoria: [muutokset.md](muutokset.md).
