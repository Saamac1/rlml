# RLML-dataformaatit

[RLML](../README.md) › RLML-dataformaatit

Oct 23, 2026 · @Seppo Säämäki

RLML 0.3:n dataformaattien erillisdokumentti. Sisältö on erotettu koostedokumentista “RLML 0.3”, ja se kattaa hyväksytyt dataformaatit. Pelilogiikan kieli RogueScript kuvataan omassa dokumentissaan, ja moottorin vastuut dokumentissa “[RLML-moottorin vastuut](../moottori/README.md)”. Lukujen numerointi on tämän dokumentin oma.

Muutoshistoria: [muutokset.md](muutokset.md).
