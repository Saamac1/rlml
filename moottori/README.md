# RLML-moottorin vastuut

[RLML](../README.md) › RLML-moottorin vastuut

Oct 23, 2026 · @Seppo Säämäki

RLML 0.3:n kolmas erillisdokumentti. Dokumentti kokoaa yhteen, mitä moottori tekee. Dataformaatit ja RogueScript kuvaavat, mitä kirjoittaja kirjoittaa. Tämä dokumentti kuvaa, mitä moottori lupaa tehdä sille: lataus, pelin tila, ajo, esitys, syöte ja tallennus. Toteutuksen kieli, tietorakenteet ja tallennustiedoston muoto on rajattu pois. Viittaukset muotoa “[D 3.3](../dataformaatit/03-tiedostot-ja-include.md#33-aloitus)” tarkoittavat dokumenttia RLML-dataformaatit ja “[RS 9.8](../roguescript/09-kohtaukset-ja-aikajanat.md#98-luonnos-ohitus-ja-alusta-aloitus)” dokumenttia RogueScript ja “[STD 10](../vakiokirjasto/10-generointi.md)” dokumenttia RLML-vakiokirjasto.

Muutoshistoria: [muutokset.md](muutokset.md).
